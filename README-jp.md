Batuk は、AI がどこで動作するか、ユーザーがどのモデルへアクセスできるか、ドキュメントがどのように検索されるか、利用状況をどのようにガバナンスするかを組織が管理するための、オープンソースのエンタープライズ AI ワークスペースです。洗練されたマルチモデルチャット体験、プライベート RAG、チームワークスペース、Microsoft Entra ID / Azure AD SSO 対応の ID、監査ワークフロー、Token 利用レポート、OpenAI 互換の社内 API を 1 つの製品として統合します。

Batuk は、小規模チーム向けのローカルファーストな主権型 AI チャットワークスペースとしても、大規模組織向けのセルフホスト AI プラットフォームとしても利用できます。ノート PC 上でローカルストレージを使って動かすことも、Docker でデプロイすることも、SQL データベースやベクトルストアへ接続することも、モデル認証情報、ドキュメント、メモリ、監査証跡を自社の運用境界内に置く管理環境へ導入することもできます。

## Batuk を選ぶ理由

Batuk は、単なるチャットボット以上のものを必要とするチームのために作られています。管理者は、AI アクセス、ドキュメント、ワークスペース、モデルルーティング、API Key、コンプライアンス証跡、組織ブランディングを 1 つの制御プレーンで管理できます。

Batuk がプライベートなエンタープライズ AI ワークスペースとして強い理由は、主権性をスローガンではなく製品要件として扱う点です。ローカルモデル、ホスト型 Frontier モデル、プライベートモデルゲートウェイ、ドキュメント RAG、ID、認可、Audit Trail、利用状況の可視化、ワークスペース境界が、同じインターフェース上で連携するように設計されています。

- **主権性を前提に設計：**ローカルモデル、ホスト型プロバイダー、プライベート OpenAI 互換エンドポイントを利用しながら、ユーザーデータ、ドキュメント、メモリ、API アクセスを管理者が制御できます。
- **エンタープライズ対応ワークスペース：**ユーザー、管理者、組織、チーム、共有ワークスペース、Microsoft Entra ID / Azure AD SSO、OAuth/OIDC、SAML、SCIM、保護された製品 API がプラットフォームに含まれます。
- **プライベートなドキュメントインテリジェンス：**ドキュメントのアップロード、テキスト抽出、チャンク化、ベクトル化、引用検索を行い、RAG をユーザー、組織、共有ワークスペース単位でスコープ化できます。
- **混乱しないモデル選択：**管理者が利用可能なプロバイダーとモデルを決め、ユーザーは Provider Settings、モデル選択、音声、Web 検索、Guardrails を備えたクリーンなチャット UI を利用します。
- **社内 AI API Gateway：**Batuk API Key と OpenAI 互換エンドポイントを通じて、管理者が承認したモデルを社内ツール、Agents、製品連携へ公開できます。
- **コンプライアンスを意識した運用：**Audit Logs、GDPR ワークフロー、Control Register、利用レポート、CSV 証跡エクスポートにより、AI 活動の理解と統制を支援します。
- **柔軟なセルフホスト：**ローカル JSON/SQLite から始め、PostgreSQL、MySQL、ChromaDB、Pinecone、Qdrant Cloud、Supabase、Docker、任意の Advanced RAG サービスへ拡張できます。
- **ホワイトラベル対応：**組織は製品名、タグライン、アクセントカラー、イニシャル、Logo を設定しつつ、Creator Attribution を維持できます。

## プラットフォーム機能

### 主権型マルチモデルチャット

Batuk は、管理者が 1 つの Provider Registry からローカル推論、クラウド LLM、ルーティングプロバイダー、カスタムモデルゲートウェイを有効化できるプライベート AI チャットワークスペースを提供します。

- Markdown レンダリング付きのストリーミングチャット。
- Provider モデルピッカーと手動モデル入力。
- ローカル評価向けの Runtime Settings と、環境変数ベースのサーバー設定。
- 永続化すべきでない会話のための Temporary Chat モード。
- フォルダ、検索、インポート、エクスポート、コピー操作を備えた個人・共有ワークスペース。
- 有効化され、選択モデルが対応している場合の OpenAI hosted web search。
- ブラウザマイク入力による OpenAI Realtime と Grok Voice セッション。
- より安全なプロンプトスクリーニングとシステム挙動のための Guardrails。
- Provider Settings、API Access、Workspace Management、Chat History、Token Usage、Enterprise Management、Audit Review のためのワークスペースツール。

### Document Chat と Enterprise RAG

Batuk は内部ドキュメントをスコープ付き AI コンテキストへ変換します。個人ファイルは個人のまま保持され、共有ワークスペース RAG は割り当てられたメンバーと管理者だけが利用できます。

- PDF、TXT、Markdown、JSON、LOG、CSV、XLS、XLSX、DOCX ファイルをアップロード。
- テキスト抽出、チャンク化、Embedding 生成、チャット中の関連コンテキスト検索。
- ローカル deterministic Embeddings、直接 Ollama `/api/embed` Embeddings、LlamaIndex Ollama Embeddings、ホスト型 OpenAI Embeddings を利用可能。
- Ollama RAG は、`embeddinggemma`、`qwen3-embedding`、`all-minilm`、`nomic-embed-text`、`mxbai-embed-large`、カスタム Ollama Embedding モデルなど、pull 済みの任意の Embedding モデルをサポートします。
- Batuk は固定サイズを強制せず、Embedding 応答ごとにベクトル次元を検出します。Ollama の次元はモデル依存、OpenAI `text-embedding-3-small` は既定で 1536、`text-embedding-3-large` は 3072 まで、ローカル deterministic Embeddings は 384 を使用します。
- ベクトルはローカル JSON、ChromaDB、Pinecone、Qdrant Cloud、Supabase Postgres/pgvector に保存できます。
- Chunks と Vectors に組織、ユーザー、ワークスペースのメタデータを保持。
- Documents ワークスペースから再インデックス、ダウンロード、削除が可能。
- 選択したベクトルストアが対応している場合、削除時にメタデータ、ソースファイル、Chunks、リモートベクトルを削除します。

### Advanced RAG と Graph Intelligence

Batuk は Python なしでも動作します。より高度なドキュメントインテリジェンスが必要な場合、任意の FastAPI バックエンドが高度な抽出、Graph RAG、ローカル ML Guardrails を追加します。

- 表、スキャンページ、複数カラムレイアウト、ページメタデータ、図、レポート、科学文書に対応した複雑 PDF 抽出。
- ドキュメント、ページ、セクション、段落、表、図、Chunks、引用を保持する構造化出力。
- Entity Extraction、Relationship Extraction、Community Detection、Graph Visualization Data、任意の Neo4j 永続化を備えた Graph RAG Ingestion。
- 設定可能な OpenAI 互換エンドポイントによる LLM ベースの Graph Extraction。
- PII、Secrets、Language、Sensitivity のローカルドキュメントスキャン。
- Document Chat 用のページ認識 Chunks とより豊かなソースコンテキスト。

### Enterprise Identity と Access Control

Batuk は Better Auth 連携と保護された API ルートにより、Enterprise Identity の基盤を提供します。

- Email/password 認証。
- ユーザー、ロール、ban、password reset、admin API の管理。
- 組織、チーム、メンバー、招待、組織ロール。
- Consent page 付き OAuth 2.1/OIDC Provider Mode。
- 企業、大学、Microsoft 365 を重視する組織向けに、環境変数だけで有効化できる One-click Microsoft Entra ID / Azure AD SSO。
- Enterprise OIDC/SAML Sign-in の SSO サポート。
- Identity Provider ワークフロー向けの SCIM Provisioning。
- Chat、Documents、Skills、Agents、Usage、Memory、Models、Attachments、Realtime Sessions、Workflows、Enterprise Operations の保護 API。

### Microsoft Entra ID / Azure AD SSO

Batuk は Microsoft 365、Entra ID、Azure AD、Teams、Outlook、SharePoint、大学の Microsoft tenant を標準化している組織向けに Microsoft SSO をサポートします。管理者は `.env` または `.env.enterprise` から One-click `Continue with Microsoft` ログインボタンを有効化でき、独自の認証コードを書く必要はありません。

Microsoft Entra ID App Registration を作成し、ローカル開発用に次の redirect URI を追加します。

```text
http://localhost:3000/api/auth/sso/callback
```

本番では、ホスト部分をデプロイ済みの `BETTER_AUTH_URL` に置き換えます。

```text
https://your-batuk-domain.com/api/auth/sso/callback
```

その後、次を設定します。

```env
BATUK_MICROSOFT_SSO_ENABLED=true
NEXT_PUBLIC_BATUK_MICROSOFT_SSO_ENABLED=true
BATUK_MICROSOFT_PROVIDER_ID=microsoft-entra
NEXT_PUBLIC_BATUK_MICROSOFT_PROVIDER_ID=microsoft-entra
NEXT_PUBLIC_BATUK_MICROSOFT_SSO_LABEL=Continue with Microsoft
BATUK_MICROSOFT_TENANT_ID=replace_with_directory_tenant_id
BATUK_MICROSOFT_CLIENT_ID=replace_with_application_client_id
BATUK_MICROSOFT_CLIENT_SECRET=replace_with_client_secret_value
BATUK_MICROSOFT_DOMAIN=example.edu,example.com
BATUK_MICROSOFT_SCOPES=openid,profile,email,offline_access
```

厳密な OIDC issuer 検証を維持するため、実際の Microsoft Directory Tenant ID を使用してください。`BATUK_MICROSOFT_DOMAIN` はカンマ区切りで複数のメールドメインを受け付けるため、大学や複数ドメインを持つ欧州組織にも適しています。

### Administration と Governance

管理者はコードを変更せずに AI アクセスとワークスペース動作を管理できます。

- owner または admin が存在しない場合の first-owner bootstrap。
- User CRUD、password resets、bans、unbans、deletion。
- 組織作成と active organization switching。
- チーム作成、招待、ロール管理。
- 共有ワークスペース作成、membership、RAG 有効化、rename、delete。
- Source、provider、model、user、chat、API key、day、month、year ごとの Token Usage Dashboard。
- Access denial、admin action、document operation、chat library mutation、privacy request、control change の Audit Trail。
- Audit Events の hash-chain integrity evidence。
- GDPR export、request、erasure workflows。
- ISO 27001 と SOC 2 control evidence register。

### 社内 AI API Gateway

Batuk ではユーザーが個人 API Key を生成し、管理者が承認したモデルを OpenAI 互換エンドポイント経由で呼び出せます。これにより Batuk は AI チャットワークスペースであるだけでなく、業務アプリ、Automation、Agent Workflows のための社内モデルアクセス層にもなります。

```bash
curl -H "Authorization: Bearer batuk_..." http://localhost:3000/api/v1/models

curl -X POST http://localhost:3000/api/v1/chat/completions \
  -H "Authorization: Bearer batuk_..." \
  -H "Content-Type: application/json" \
  -d '{"model":"company/support-large","messages":[{"role":"user","content":"Hello"}]}'
```

API Key はユーザー単位でスコープされ、ハッシュとして保存されます。管理者は `company/support-large` や `batuk/qwen3.7-max` のようなルートを公開し、Batuk 内で設定した provider、model、base URL にマッピングできます。利用状況は chat、API completions、search で個別に記録されます。

## Storage、RAG、Deployment Options

Batuk は意図的にモジュール化されています。チームはローカルストレージから始め、導入が進むにつれてエンタープライズ級インフラへ移行できます。

| レイヤー | 既定 | Enterprise Options |
| --- | --- | --- |
| Authentication | SQLite | SQLite、MySQL、PostgreSQL、MS SQL、MongoDB |
| Product data | Local JSON | SQLite、MySQL、PostgreSQL |
| Documents | Local file storage | 設定可能な local または container path |
| Branding logos | `public/branding` | 設定可能な local または container path |
| Vectors | Local JSON | ChromaDB、Pinecone、Qdrant Cloud、Supabase pgvector |
| Advanced document intelligence | Built-in text extraction | Optional FastAPI backend、Graph RAG、Neo4j |

Product data には chats、folders、workspaces、document metadata、chunks、memories、API keys、model routes、skills、MCP integration records、agents、workflows、token usage、branding、compliance records、GDPR requests、audit trails が含まれます。

個人 product data はサインインユーザーにスコープされます。共有ワークスペースデータはワークスペースにスコープされ、membership または admin checks の後にのみロードされます。

## MCP Integrations

Batuk には、tools、resources、prompts をワークスペースへ接続する MCP dashboard が含まれます。チームは streamable HTTP、SSE、stdio MCP servers を登録し、capabilities を発見し、resources を確認し、active MCP integration を chat context として選択できます。

プリセット connector categories には productivity、CRM、payments、analytics、project management、databases、search、browser automation、developer tools、custom internal MCP servers が含まれます。Batuk は MCP integration configuration をブラウザへ返す前に、保存済み client secrets と tokens を redaction します。

MCP support により、Batuk は単なる chat surface ではなく、models、documents、tools、enterprise systems が admin-controlled access の下で連携する governed AI workspace になります。

## セルフホスト Deployment

Batuk にはセルフホスト Enterprise 環境向けの Docker と database assets が含まれます。

```text
Dockerfile
docker-compose.yml
.env.enterprise.example
database/sqlite/001_enterprise_data.sql
database/postgresql/001_enterprise_data.sql
database/mysql/001_enterprise_data.sql
```

runtime environment file を作成して stack を開始します。

```bash
cp .env.enterprise.example .env.enterprise
docker compose up --build
```

必要に応じて optional service profiles を有効化します。

```bash
docker compose --profile postgres up --build
docker compose --profile mysql up --build
docker compose --profile postgres --profile chroma up --build
docker compose --profile ollama up --build
docker compose --profile advanced-rag up --build
docker compose --profile advanced-rag --profile neo4j up --build
```

Vercel、Render、Railway の deployment buttons が利用できます。private SQL services、local vector search、controlled file storage、local models、Advanced RAG、internal network deployment が必要なチームには Docker Compose が推奨です。
